# Browser tests

`tests/browser/*.mjs` are node scripts that drive a real browser through Playwright against the wp-env site and exit non-zero on a failed assertion. Each one is an admin screen, and each asserts what a user sees on it, never how the admin script does it, so the scripts can be rewritten under them.

    make test:browser                  # every screen, in Chromium and in WebKit
    make test:browser SCREEN=settings  # one screen (npm run test:browser -- settings)
    GLSR_ENGINE=webkit node tests/browser/settings.mjs   # one screen in one engine

`harness.mjs` holds what they share: `launch()`, `login()`, `reporter()` for the PASS, FAIL and INFO lines, `pageErrorsOf()` for a page's uncaught errors, `restRequest()`, `createReview()` and `deleteReview()` (through the REST API as the logged-in administrator), and `wpCli()` for what REST cannot do (a pending status, a term, a setting). `GLSR_ENGINE=chromium|webkit` picks the engine, `GLSR_BROWSER` the Chromium-family binary (Brave by default), and `WP_ENV_PORT` overrides the port `.wp-env.json` names (8890). WebKit is the build Playwright ships: `npx playwright install webkit` after a Playwright update.

Every script creates what it needs and deletes it in a `finally`, so a failed run leaves nothing on the site; a setting it changes is read inside the same `try` and restored in that `finally`, never before the `try`. An INFO line names a behaviour the site cannot show (no colour setting in core, no Widgets screen or Customizer widgets without a classic theme installed, the verify icon until a snippet or addon turns `verification/enabled` on) so the run says what it did not cover.

| Script | Screen | What it asserts |
|---|---|---|
| `reviews-list.mjs` | the review list | the status toggle redraws the row and the counts, and shows the error of a change that fails; the pin and verify toggles, and the pin's notice; the author filter's dropdown opens, lists and chooses, a click in another field closes it without taking the focus, and Enter chooses nothing while it is searching; a Screen Options filter checkbox hides its dropdown and the choice survives a reload; quick edit fills the content and response fields, and Enter starts a new line in the response on a page that is ready late |
| `review-editor.mjs` | the review editor | the assigned posts and users searches find, assign and unassign, a title shows as text with no HTML entity, the arrow keys colour the result they highlight, and an emptied search closes its results; the publish box's pinned control edits, saves and cancels; the Edit Details toggle enables the fields; the verification request button where the setting shows it |
| `category-quick-edit.mjs` | the categories screen | quick edit fills Priority from the row |
| `settings.mjs` | Settings | the tabs and their reload; a dependent field shows and hides with its control; a template-editor tag inserts at the cursor; a reset button restores the default; the Strings tab's search adds a row and keeps its term, its delete removes it and an emptied search closes its results; the License Key field's show/hide toggle, and its tooltip after Verify draws the row again (on a site that shows the row). Nothing is saved |
| `tools.mjs` | Tools | the console reloads, changes level and clears; System Info loads, on its tab and on a reload of it; a tool runs and shows its notice; a card heading toggles and an expand link opens its card; the Import Settings card is open again after its form reloads the page; a CSV imports its two valid rows through the progress bar and its notice names the warning of the row it skipped, and the bar fills in the count of an attachment stage's message; the bar follows its button when the window is resized and Cancel leaves its message in it; an upload the server refuses shows the upload size message; the rollback dialog opens and closes on Escape |
| `documentation.mjs` | Help & Support | the tabs; a code sample is highlighted; copying a sample gives plain text (Chromium) |
| `welcome.mjs` | Welcome | the tabs; a playlist item loads its video frame |
| `dashboard.mjs` | Dashboard | the widget renders with its stylesheet and the admin bundle stays off; a seeded Gatekeeper notice shows, its X sends the dismiss request and removes it, and a reload does not bring it back |
| `notices.mjs` | the notices of the plugin's screens | the banner shows at the top of the page header; the premium notice's install link asks the store to connect, on a site whose key includes premium; a popup leaves the message of WordPress on the categories screen |
| `plugins.mjs` | Plugins | the deactivation dialog opens with a reason removed by a snippet, takes a reason and closes without deactivating |
| `block-editor.mjs` | a page's block editor, the Site Editor and the published page | a Review Form block's preview draws its rating field as stars in both editors and every module it names loads; the preview keeps no field values while Enable Session Storage is on, and the published form keeps them; the multi select takes the focus with its list closed and opens it at the Down Arrow or a press, over the controls below with nothing showing through; it is 40px empty and its search stays under a 26px picked item, the Left Arrow moves the focus to the item, Enter brings it back and Backspace removes the item; while a search loads and when it finds nothing its list is as tall as one item, the loading line with a 12px spinner where an item has its check and the "No results found." line at the list's start; the single select is a button that opens its search and what it finds, names the picked item and is emptied by its Clear button; the stylesheet's rules reach no WordPress field |
| `foreign-screens.mjs` | a post's block editor, the posts list, the Site Editor, the Widgets screen and the Customizer | none loads the admin bundle or its stylesheet; the block editor has the rating range in the public config; the Widgets screen and the Customizer load the widgets stylesheet and nothing else, on a classic theme (Twenty Twenty-One, when it is installed) |

The importer screen (`admin.php?import=site-review-form`) is premium's and is covered when premium is active on the site.
